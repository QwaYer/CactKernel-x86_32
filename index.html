🚀 Core Features

🧠

Memory Manager

PMM, VMM, heap, slab, mmap, COW, swap. Complete virtual memory support with page faults and OOM handling.

⏱️

MLFQ Scheduler

4-level multilevel feedback queue with priority boosting, anti-starvation, and sleep queue management.

💾

Filesystems

ext4, VFS, devfs, procfs, mntfs, etcfs, tmpfs, binfs, sbinfs, libfs with full read/write support.

🌐

Network Stack

Ethernet, ARP, IPv4, ICMP, TCP/UDP sockets, smoltcp, virtio-net, DNS resolver and DHCP client.

🔌

Drivers

PCI, AHCI, NVMe, xHCI, USB, PS/2, virtio-net, framebuffer console with MTRR and shadow buffer.

🔒

Synchronization

Spinlock, IRQ spinlock, mutex, semaphore. Full multi-process synchronization primitives.

🧬

Processes

fork, exec, exit, waitpid. 13 signals, sigaction, full multi-process execution support.

📦

ELF & Dynamic Linking

Complete ELF loader, dynamic linking, i386 relocations including R_386_COPY support.

🎯

Multiboot2

Full Multiboot2 bootloader support, framebuffer, memory map, modules and PCI configuration.

🏗️ Quick Start

Full Build (from workspace):

./build-cact-qemu.sh # full ISO + disk, 1 command
./build-cact-qemu.sh && CACT_ISO=build/cact.iso CactKernel-x86_32/run_qemu.sh
RUN_QEMU=1 ./build-cact-qemu.sh # build + run

Kernel Only:

make -j$(nproc) # kernel + ISO
make -j$(nproc) kernel # kernel only
./run_qemu.sh # run in QEMU

Requirements:

• gcc -m32 (multilib on amd64)
• nasm — Multiboot2 entry
• ld -m elf_i386 — GNU binutils
• cargo +nightly — Rust subsystems
• grub-mkrescue + xorriso — ISO creation
• qemu-img, mkfs.ext4 — Disk images

💾 Memory Architecture (x86_32)

0xC0000000 ├─ Kernel-only (ring 0)
0xBF000000 ├─ User stack floor
0xBEFFF000 ├─ Per-process sigreturn trampoline
0xB0000000 ├─ SHM ceiling (SHM_VA_LIMIT)
0xA0000000 ├─ SHM base (SHM_VA_BASE)
0x80000000 ├─ User heap ceiling
0x40000000 ├─ mmap + brk region (256 regions max)
0x08048000 ├─ Typical ELF PT_LOAD base
0x00000000 └─ NULL / guard page
